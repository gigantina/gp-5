## Постановка задачи


Задача 1. Задача детекции объектов на изображениях.

Автоматизировать распознавание фруктов и овощей на кассе самообслуживания с помощью компьютерного зрения.



Задача 2. Задача бинарной классификации табличных данных.

Выявлять подозрительные покупки на кассе самообслуживания на основе табличных данных о транзакции.


Подробно про бизнес-задачи, про постановку задачи в терминал DL расписали в файле -- https://docs.google.com/document/d/12JwQuxRLTZtDmTTZEJ7vDUV1lF6jeFNpD-EIEq4OKfs/edit?usp=sharing 

## Описание проекта

Проект посвящен автоматизации касс самообслуживания в розничной торговле с использованием методов глубокого обучения.

Система решает две взаимосвязанные бизнес-задачи:

### 1. Автоматическое распознавание товаров по изображению

Для фруктов, овощей и других товаров без штрихкода используется модель детекции объектов на изображениях. Камера кассы анализирует рабочую зону и определяет:

- какие товары находятся перед камерой;
- количество обнаруженных объектов;
- расположение каждого объекта на изображении;
- наличие нескольких разных типов товаров одновременно.

Для решения задачи используются как самописные модели, так и архитектура YOLO (библиотека для компьютерного зрения).

**Вход:** изображение с камеры кассы самообслуживания.

**Выход:** классы товаров, координаты bounding boxes и уверенность модели для каждого объекта.

**Основная метрика:** map (50-95, 50, 75)

Данные взяли отсюда -- https://www.kaggle.com/datasets/kvnpatel/fruits-vegetable-detection-for-yolov4/data 



### 2. Выявление подозрительных транзакций

После оформления покупки система анализирует итоговую транзакцию и оценивает вероятность мошенничества или ошибок при самообслуживании.

Модель использует табличные признаки покупки:

- сумма чека;
- количество товаров;
- состав корзины;
- скидки;
- корректировки и отмены позиций;
- другие характеристики транзакции.

Для решения задачи применяется полносвязная нейронная сеть (Fully Connected Neural Network).

**Вход:** признаки транзакции.

**Выход:** риск-скор (вероятность подозрительной транзакции).

**Основные метрики:**
- ROC-AUC;
- Precision;
- Recall;
- F0.5-score;
- Profit (бизнесовая метрика конретно для этой задачи, подробно расскажем во время презентации про эту метрику).

Данные взяли отсюда -- https://www.kaggle.com/datasets/oscarm524/fraud-detection-in-grocery-shopping-transactions


## Как это все выглядит для покупателя

1. Покупатель сканирует товары со штрихкодом.
2. Фрукты и овощи распознаются камерой автоматически.
3. Система предлагает оформить найденные товары и добавить их в чек.
4. После формирования корзины рассчитывается риск-скор транзакции.
5. При низком риске покупатель оплачивает покупку.
6. При высоком риске система может инициировать дополнительную проверку сотрудником.

## Общая бизнес-ценность проекта

- ускорение процесса покупки;
- снижение количества ошибок при оформлении товаров;
- уменьшение нагрузки на сотрудников магазина;
- повышение удобства касс самообслуживания;
- снижение потерь от мошенничества и некорректных покупок;
- переход от случайных проверок к риск-ориентированному контролю.
